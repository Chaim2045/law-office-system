# Rubric — management service-card reading-pane redesign (Track-2 PR-1)

**Scope:** frontend-only, DEV, admin-critical. The management tab's per-service card (`buildManageDetail` → `.management-service-card` on `clients.html`) read as "generic AI" (blue accent rail on a rounded card, a bare inline-styled packages table, a heavy header). This redesigns it to a compact reading-pane card for **all types**: a management-forked header (icon + name + type·status dot + a RELATIVE hours meter), a **collapsible** packages disclosure (native `<details>` for >1, inline for 1), and a calm footer. **DISPLAY ONLY** — every injector/handler contract is byte-preserved. The legal **stepper refinement** + override calm-treatment are a follow-up (PR-2); this PR gives legal the new shell+header+footer with its existing stepper.

**Change:** 7 files. `js/ui/UnifiedServiceCard.js` (new `buildManageHeader` + `manageMeterStatus`; `buildManageDetail` swaps `buildIdentityBand`→`buildManageHeader`; `buildServiceInfo` hours→packages-only + legal/fixed self-wrapped; `buildPackagesBreakdown`→disclosure; dead `statusPillHtml` removed), `css/clients-modals.css` (de-rail root + `max-height:none` reveal + `.msc-*` block + compact footer + mobile tap-targets; removed the now-dead `.usc-identity-status` pill CSS the deleted `statusPillHtml` orphaned — the report tab never emitted it), `css/design-system.css` (ADDITIVE: `--orange-darker` #c2410c — a WCAG-AA-on-white orange for the "high" remaining text, since `--orange-dark` is only 3.56:1), `clients.html` (`?v=` bump on `clients-modals.css` + `UnifiedServiceCard.js`), `tests/unit/admin-panel/manage-detail-equality.test.ts` (re-anchored to `.msc-*`), `tests/unit/admin-panel/card-redesign.test.ts` (new behavioral guard), the rubric. **NO** backend / CF / rules / report-tab change (`design-system.css` add is additive; report `.usc-identity*` band untouched).
